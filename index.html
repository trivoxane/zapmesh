Core Features

Everything you need on your LAN.

Simple local communication and sharing, designed specifically for Windows.

◌

LAN Discovery

Automatically discover other ZapMesh users connected to the same local network.

💬

Direct Chat

Send instant one-to-one text messages directly between Windows devices.

👥

Group Chat

Create group conversations and communicate with multiple LAN users.

📎

File Sharing

Send files directly between supported ZapMesh devices with transfer progress.

📁

Folder Sharing

Share folders while preserving their internal structure.

📋

Clipboard Sharing

Presence Status

System Tray

Notifications

Getting Started

How ZapMesh works.

No complicated setup for local network communication.

01

Install or Extract

Install ZapMesh normally or use the portable Windows version without installation.

02

Connect to the Same LAN

Connect the Windows devices to the same Wi-Fi or Ethernet network.

03

Discover Nearby Users

ZapMesh automatically discovers available ZapMesh devices on the local network.

04

Start Communicating

Chat directly, create groups, and share supported files and content.
