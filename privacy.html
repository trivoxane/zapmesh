ZapMesh

Privacy Policy

Effective Date: August 14, 2026

ZapMesh is a Windows desktop application developed and maintained by JK Voxane. This Privacy Policy explains how ZapMesh handles information during normal use of the application.

1. Local Network Communication

ZapMesh is designed for communication between ZapMesh devices on the same Local Area Network (LAN). The application uses local network communication for peer discovery, presence updates, messaging, groups, and supported file transfers.

2. Information Stored Locally

ZapMesh may store application settings locally on the Windows device, including the display name, preferences, download directory, notification preferences, and license activation information.

3. Messages and Shared Content

ZapMesh supports one-to-one messaging, group messaging, file sharing, folder sharing, and explicit clipboard sharing.

Clipboard access occurs only when the user explicitly chooses to share clipboard content. ZapMesh does not continuously monitor clipboard contents for sharing.

4. Received Files

Received files and folders are saved to the user's configured ZapMesh download directory.

ZapMesh does not automatically execute received files.

5. Feedback and Support

When a user chooses to send feedback, request a feature, or report a problem, ZapMesh may prepare an email for the user's default mail application addressed to:

trivoxane@gmail.com

Support reports may include basic technical information such as the ZapMesh version, Windows version, architecture, and .NET runtime.

ZapMesh does not intentionally include chat messages, file contents, clipboard contents, or passwords in automated support diagnostics.

6. Analytics and Telemetry

ZapMesh v1.0.0 does not intentionally collect chat content, file contents, or clipboard contents for analytics.

7. License Information

ZapMesh contains a licensing system for unlocking premium functionality. License information required by the application is stored locally.

ZapMesh v1.0.0 is currently distributed free of charge. Premium activation functionality exists in the application but paid activation licenses are not currently being sold or issued.

8. Uninstallation and Data Removal

Uninstalling ZapMesh removes application-specific installation files, settings, activation data, cache, and related application data according to the application's uninstall behavior.

User-owned files stored in the ZapMesh download directory are not silently deleted during normal uninstallation.
